Personal backup utility

Music stays playing.
Memories stay protected.

Jukebox Backups is a personal utility for backing up the configuration and persistent data of a Raspberry Pi-powered music jukebox. It uses restic to encrypt backup data on the device and rclone to transfer encrypted snapshots to the owner's Google Drive.

How Google Drive data is handledView public project information

How it works

Three steps to a safer recovery

01 / SELECT

Collect local state

Read the jukebox's selected settings, service configuration, and persistent playback and library state from its Raspberry Pi.

02 / ENCRYPT

Encrypt before uploading

Restic encrypts the backup archive on the Raspberry Pi. The encryption password is held separately from Google Drive.

03 / STORE

Save to the owner's Drive

Rclone uses the owner's explicit Google authorisation to manage encrypted backup files in a dedicated Jukebox-Pi/restic folder.

Important: This website is an informational page, not a sign-in or backup portal. It does not request your Google password, collect Google Drive files, or hold backup encryption keys. Backups run on the owner's Raspberry Pi only after setup and authorisation. Google Drive storage is distinct from a bootable full-system image backup.

For details about what Google account data the utility accesses, how it is protected, and how to revoke access, read the Jukebox Backups privacy policy.
