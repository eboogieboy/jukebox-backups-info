Personal-use utility

Terms of use

Last updated: 2 November 2026

Jukebox Backups is a personal Raspberry Pi backup utility, not a commercial storage, cloud-hosting or disaster-recovery service. Its public website is provided solely to explain the utility's functionality and how it handles Google account data.

Owner-controlled setup

The owner decides whether to authorise Google Drive, install backup software, retain backups and restore files. The utility is intended solely for the owner and their personally authorised devices. No account, purchase or subscription is offered through this public website.

No guaranteed recovery

Backups require working storage, correct configuration, available encryption credentials and successful restoration testing. Merely configuring an OAuth client does not create a backup. The owner is responsible for monitoring backup status, protecting encryption keys, and keeping separate copies as appropriate.

Third-party platforms

Google Drive storage is subject to Google's terms and policies. GitHub hosts the public informational pages under GitHub's terms. Neither Google nor GitHub operates the Jukebox Backups utility.

Privacy and contact

How the application handles Google user data is explained in our privacy policy. Questions can be raised through the public GitHub issue tracker; never post credentials or private backup data there.
